# PA-WAVE: 居民电器录波数据集v1.0

本项目收录常用居民电器的电压、电流录波，录波文件采用 COMTRADE 1999/ASCII 格式，可用于非侵入式负荷辨识（NILM）、负荷特征提取与互感器特性对比。同一负载分别用**电磁式电流互感器**和**霍尔电流互感器**采集，数据集持续补充。

## 采集条件

- 单相 220 V / 50 Hz 市电，同一台录波装置，AC_V、AC_I 两个模拟量通道。
- 采样率 12,800 Hz，采样值以 16 位有符号整数存储（−32768 ~ 32767）。
- 电压通道为被测电器的供电电压，电流通道只包含被测电器电流。
- 每个设备目录下的 `readme.txt` 记录了该设备的测试说明。



## 目录结构

```
.
├── data/
│   ├── 电磁CT/<设备类别>/<型号>/[<工况>/]<记录名>.cfg|.dat
│   └── 霍尔CT/<设备类别>/<型号>/[<工况>/]<记录名>.cfg|.dat
├── doc/img/
├── LICENSE
├── README.md
└── README_en.md
```

- `<记录名>` 形如 `BAYxx_xxxx_YYYYMMDD_HHMMSS_mmm`，与 CFG 中的起始时间一致。
- 工况目录名中的 `P` 表示百分比，如 `电量P10` 即电量 10%。
- 路径含中文，请在 UTF-8 环境下克隆和解压。



## 文件格式

每组记录由同名的 `.cfg` 与 `.dat` 组成，遵循 COMTRADE 1999（IEEE C37.111-1999）。

**CFG**（11 行，CRLF）：

| 行 | 内容 | 本数据集取值 |
|---|---|---|
| 1 | 站名, 装置名, 版本 | `Demo Station,Demo Device V1.00,1999` |
| 2 | 通道数 | `2,2A,0D` |
| 3–4 | 模拟量通道定义 | 序号, 名称, 相别, 单元, 单位, `a`, `b`, skew, min, max, primary, secondary, PS |
| 5 | 工频 | `50` |
| 6 | 采样率段数 | `1` |
| 7 | 采样率, 末点序号 | `12800,N` |
| 8 | 起始时间 | `dd/mm/yyyy,hh:mm:ss.ssssss` |
| 9 | 触发时间 | 与起始时间相同 |
| 10 | 数据格式 | `ASCII` |
| 11 | 时间乘数 | `1.000` |

**DAT**（每行 4 列，CRLF）：

```
采样序号,相对时间戳(µs),AC_V,AC_I
1,0,3267,35
2,78,3232,36
```

物理量按 CFG 通道行换算：`实际值 = a × 采样值 + b`。`a` 为通道行第 6 个字段，`b` 为第 7 个字段；各设备量程不同，务必从各自 CFG 读取，不要套用统一系数。

### 时间戳说明

DAT 第 2 列是**相对起始时间**的微秒数，为线性轴，满足 `t_i = (i−1) × 10⁶ / 12800`，步长 78/79 µs 交替，单调递增，末点与 CFG 的「起始时间 + (N−1)/采样率」相差 <1 µs。



## 快速开始

环境：Python 3.8+；读取示例需要 numpy。

```python
import numpy as np

def load(cfg_path):
    """读取一组记录，返回 t (s)、u (V)、i (A)。"""
    lines = open(cfg_path, encoding='ascii').read().splitlines()
    nch = int(lines[1].split(',')[1].rstrip('A'))
    ch = [x.split(',') for x in lines[2:2 + nch]]
    dat = np.loadtxt(cfg_path[:-4] + '.dat', delimiter=',')

    t = dat[:, 1] / 1e6
    u = dat[:, 2] * float(ch[0][5]) + float(ch[0][6])
    i = dat[:, 3] * float(ch[1][5]) + float(ch[1][6])
    return t, u, i

t, u, i = load('data/电磁CT/电风扇/奥克斯FS1603RC/高档风速/BAYxx_xxxx_20261029_093457_017.cfg')
print(t.shape, u.shape, i.shape)
```



## 已知限制

- **固定窗口、无事件标签**：触发时刻等于起始时刻（源数据即如此），录制为固定长度窗口，不含触发前预触发段；启停、插拔等事件时刻需自行从波形判定。
- **小电流段存在批次差异**：待机、低速风扇等低功率工况下，两批电流有效值差异较明显，跨批次绝对值不宜直接等同，建议以同批次内的相对变化或波形特征为准。
- **机型与个体差异**：手机两批分别为 iPhone 17 与华为 mate60pro；设备型号为实测记录，同型号不同个体可能存在差异。
